**Method**

Firstly, the metre stick was put into the first hole (as in Figure 1) and the value for _r_ was measured. After that, the metre stick was released with a small amplitude (for more reliable results) and as soon as the stick passed the stand, the timer started. After one period was completed (that is, the metre stick passed the stand again from the same direction as it was released), the timer was stopped and this value for _T_ was taken down. This was repeated 5 times so as to get 5 values for _T_ for one _r_ value and these were recorded. Then the metre stick was adjusted to the second hole and the same process was followed (distance measured and then 5 _T_ values are retrieved), and similarly, this was done for the third, fourth and fifth hole
