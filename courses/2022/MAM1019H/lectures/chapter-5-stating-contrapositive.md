Chapter 5 Stating Contrapositive

1.  If n is odd, then n2 is odd
2.  If n is even, then n2 is even
3.  If a and b are even, then a2(b2\-2b) is even
4.  If a | b, then a | bc
5.  If x≥0, then x2+5x≥0
6.  If x≤-1, then x3\-x≤0
7.  If a is odd or b is odd, then ab is odd or a+b is odd
8.  If x<0, then x5\-4x4+3x3\-x2+3x-4<0
9.  If 3 | n, then 3 | n2
10.  If x | y or x | z, then x | yz
11.  If x is odd and y is even, then x2(y+3) is odd
12.  If a is even, then 4 | a2
13.  If x < 0, then x5+7x3+5x < x4 + x2 + 8
